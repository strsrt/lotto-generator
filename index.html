자기소개

컴퓨터 보안에도 관심이 많아서, 나중에 에이전트가 다루게 될 데이터와 권한, 접속 환경 같은 부분을 안전하게 설계하는 관점도 함께 공부하고 있습니다.

Claude Code AI 에이전트 제조 개발 중

공장 제조 공정에서 실무자를 보조하는 에이전트를 Claude Code 기반으로 개발하고 있습니다. 공정 흐름을 이해하고, 상황에 맞는 정보 제공이나 작업 보조를 할 수 있는 방향을 목표로 잡고 있습니다.

단순히 모델을 호출하는 수준이 아니라, 어떤 맥락에서 어떤 판단을 거쳐 응답해야 하는지까지 구조적으로 설계해보는 시도를 하고 있습니다. 프롬프트 설계, 도구 연결, 상태 관리 같은 부분을 하나씩 익히는 중입니다.
